# Portfolio-Project

Welcome to my portfolio! This repository contains projects demonstrating my skills in data analytics, business intelligence, Python, SQL, and automation.

## Projects

### 1. Branch Operational Efficiency Analysis | Python, pandas, PuLP, openpyxl

**Data Analytics | Linear Programming | Reporting Automation**

Developed a Python-based Data Envelopment Analysis (DEA) tool to evaluate the relative operational efficiency of branches using multiple resource inputs and business outputs. The project automates data processing, branch-level optimization, and Excel reporting to support comparative performance analysis.

**Key Highlights:**

- **Data Processing:** Parsed structured TXT files using Python and pandas, including numeric conversion and input/output field validation.
- **Optimization Modeling:** Implemented a constant-returns-to-scale (CCR) DEA model using PuLP to calculate relative efficiency scores for each branch.
- **Automated Reporting:** Generated Excel workbooks containing efficiency scores, solver statuses, original input/output data, and optimized model weights.
- **Validation:** Successfully solved all four sample DEA models to optimality and verified the generated report.

**Tech Stack:** Python, pandas, PuLP, openpyxl, Linear Programming, DEA

### 2. Sales Performance Dashboard | Power BI, MySQL, AWS RDS

**Business Intelligence | Sales Analytics | Data Modeling | KPI Reporting**

Developed an interactive Power BI dashboard to monitor sales performance and support data-driven business decisions. Built a cloud-hosted MySQL database using Amazon RDS, transformed sales data with Power Query, and implemented a relational data model with DAX measures to analyze key business performance indicators.

**Key Highlights:**

- **Cloud Database Integration:** Configured Amazon RDS for MySQL, imported structured sales data, and established a connection to Power BI for analytical reporting.
- **Data Transformation & Modeling:** Cleaned and transformed sales data using Power Query, developed a relational data model, and created DAX measures for KPI calculations.
- **Interactive Dashboard Development:** Designed and published a Power BI dashboard featuring KPI cards, scorecards, and comparative visualizations to monitor sales performance, revenue trends, and product performance.
- **Business Intelligence Reporting:** Consolidated multiple sales metrics into an interactive reporting interface to support performance monitoring and business decision-making.

**Tech Stack:** Power BI, MySQL, AWS RDS, Power Query, DAX, Data Modeling, Data Visualization

### 3. Customer Behavior Analysis for Online Learning Platform | SQL, Tableau

**Customer Analytics | User Engagement | Cohort Analysis | Business Intelligence**

Analyzed student engagement and learning behavior on an online education platform to understand user activity, retention, and free-to-paid conversion patterns. Used SQL to transform student interaction and subscription data into analytical datasets and developed a five-page interactive Tableau dashboard to monitor KPIs, compare free and paid users, and support data-driven marketing and product decisions.

**Key Highlights:**

- **SQL Data Analysis:** Queried and joined student engagement, course activity, and subscription data; created SQL views and calculated fields to identify user activity and subscription status over time.
- **Interactive Dashboard Development:** Built a five-page Tableau dashboard featuring student engagement, onboarding, cohort retention, learning activity, and platform performance metrics, with interactive filters for dates and subscription status.
- **Cohort & Retention Analysis:** Grouped students by onboarding month to evaluate retention trends, compare free and paid users, and identify differences in long-term engagement.
- **Business Insights:** Analyzed engagement trends and marketing campaign activity, identifying a threefold increase in daily student engagement during a three-day free-access promotion and opportunities to improve user retention.

**Tech Stack:** SQL, Tableau, Data Visualization, Cohort Analysis, KPI Reporting
